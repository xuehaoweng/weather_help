# Roadmap

## Near Term

- PWA install support
- Local favorite locations: home, office, school, parents
- Rain-before reminders
- Better empty/error states for QWeather API limits
- Screenshot assets and demo GIF for README
- English UI toggle

## Product Experiments

- Commute reminder templates
- Outdoor activity score for running, cycling, fishing, camping
- Family health mode for children, older adults, allergies, UV exposure
- Shareable weather cards
- Desktop/mobile widgets

## Deployment

- Docker image publishing
- One-click deploy templates
- JWT authentication support for QWeather
- Server-side persistent cache

## Longer Term

- WeChat Mini Program version
- Air quality module
- Typhoon and coastal weather mode
- Tide and solar radiation modules
- B2B weather dashboard for venues, campsites, farms, and solar stations
